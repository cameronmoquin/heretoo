Logic: the four questions and the named flaws

Math, Logic & English · 2 min read

State says the section tests inferences, justifying conclusions, finding flaws, and identifying assumptions. Read the stem first so you know which of the four you're doing before you read the argument.

Inference: what must be true, not what is probably true. If it needs an extra assumption, it's not an inference.

Assumption: the unstated bridge between evidence and conclusion. Test it by negating: if denying the option kills the argument, it's the assumption.

Flaw: name it. Affirming the consequent (if A then B; B; so A). Denying the antecedent (if A then B; not A; so not B). Post hoc (after, therefore because). Composition (parts to whole) and division (whole to parts). False dilemma (only two options). Appeal to ignorance (unproven, so false). Hasty generalization (tiny sample). Ad hominem. Circular reasoning.

Parallel flaw: find the flaw's name first, then match the name, ignoring subject matter. A question about treaties and an option about cats can share a flaw.
