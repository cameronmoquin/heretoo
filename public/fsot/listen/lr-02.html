Logic Drill 2, The Named Flaws

Logical Reasoning · 6:33 · Episode 9

Transcript

Logic drill two: the named flaws. Quick recap of drill one's moves; say them with me. The test for an inference? It must be true — if it needs one extra assumption, it isn't one. The test for an assumption? Negate it; if the argument dies, that was it. Good. Today: flaws. The skill is naming — a flaw you can name is a flaw you can find in three seconds, and on parallel-flaw questions the name is the whole answer. Same format as before: argument twice, question, silence, answer out loud. Argument one. Every member of the trade delegation speaks excellent French. Therefore the delegation will negotiate excellently in Paris. Again: every member speaks excellent French; therefore the delegation will negotiate excellently. Name the flaw. Out loud. Composition: assuming the whole has the property of its parts. Eleven excellent violinists are not necessarily an excellent orchestra; a delegation of fluent speakers can still negotiate badly. The mirror image is division — the whole to the parts: the embassy is efficient, so every officer in it is efficient. Same crime, opposite direction. When an argument jumps between a group and its members, check the direction of the jump. Argument two. No study has ever proven that the aid program reduces corruption. So the program clearly does not reduce corruption. Again: no study has proven it works; so it does not work. Name it. Appeal to ignorance: treating the absence of proof as proof of absence. Unproven and false are different things — maybe nobody has studied it properly. And notice it cuts both ways: nobody has proven the program doesn't work, so it works, is the same flaw wearing the other shoe. The honest conclusion from no evidence is no conclusion. Argument three. Either we station troops in the region, or we abandon our allies entirely. We cannot abandon our allies. So we must station troops. Again: either troops or abandonment; not abandonment; therefore troops. Name the flaw. False dilemma. The logical form — disjunctive syllogism — is perfectly valid; the crime is in the premise, which pretends two options exhaust the menu. Sanctions, aid, basing agreements, security guarantees: the excluded middle is where actual diplomacy lives. When you hear either-or, ask who decided there were only two doors. Argument four. The senator's argument for the treaty should be rejected. After all, she owns stock in companies that would profit from it. Again: reject her argument for the treaty; she owns stock that would profit. Name it. Ad hominem — attacking the arguer, not the argument. Her conflict of interest is a fair reason to scrutinize her claims harder; it is never, by itself, a reason to call the argument false. Arguments don't inherit the sins of their owners. The subtle version the test likes: dismissing an argument because of who funds it, or because the speaker is inconsistent — you say we should conserve fuel, yet you fly. Hypocrisy is a character flaw, not a counterargument. Argument five. Free trade benefits every nation, because open markets make all countries better off. Again: free trade benefits every nation, because open markets make all countries better off. Name the flaw. Circular reasoning: the premise is the conclusion in a different coat. Open markets making all countries better off is not evidence that free trade benefits every nation; it is the same claim, restated. The tell is that you can swap premise and conclusion and nothing changes. A real argument moves; a circle spins. Argument six, and this one is a two-parter, the parallel-flaw drill. First argument: If a country defaults, its currency falls. Ruritania's currency has fallen. So Ruritania has defaulted. Name that flaw first. Affirming the consequent: if A then B; B; therefore A. Currencies fall for a dozen reasons; the arrow only runs one way. Now, which of these two commits the same flaw? Option one: if it rains, the streets are wet; the streets are wet; so it rained. Option two: if it rains, the streets are wet; it did not rain; so the streets are not wet. Option one — wet streets, so it rained — same shape: if A then B; B; therefore A. Option two is the other classic, denying the antecedent: not A, therefore not B, ignoring that sprinklers exist. Notice what you just did: you matched on shape, ignoring subject matter entirely. Currencies and rain, one flaw. That is exactly how parallel-flaw questions are answered: name first, match the name, never match the topic. The collection so far, say each name as I define it. Whole from parts? Composition. Parts from whole? Division. Absence of proof as proof? Appeal to ignorance. Two doors on a ten-door corridor? False dilemma. Shooting the messenger? Ad hominem. Premise equals conclusion? Circular reasoning. If A then B, B, so A? Affirming the consequent. Not A, so not B? Denying the antecedent. And from last drill: after, therefore because? Post hoc. Tiny sample, big claim? Hasty generalization. That's ten named flaws — the working vocabulary of the section. Next drill: strengthen and weaken, where alternative causes earn their keep. Thanks for listening.
